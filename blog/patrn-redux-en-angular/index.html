Redux en Angular con NgRx: guía práctica

Oct 23, 2024
angular redux estado

Redux es un patrón de gestión de estado que ayuda a mantener los cambios de una aplicación explícitos y predecibles. En Angular, NgRx Store ofrece herramientas inspiradas en Redux y se integra con RxJS. En esta guía crearás un contador sencillo para ver el flujo completo: estado, acciones, reducer y selección de datos desde un componente.

Qué es Redux y cómo organiza el estado

Redux organiza el estado compartido en un store y describe los cambios mediante acciones que procesa un reducer. Sus principios habituales son:

  1. Fuente única de verdad: el estado compartido vive en el store.
  2. Estado inmutable: no se modifica directamente; se producen nuevos valores.
  3. Cambios explícitos: se despachan acciones y un reducer determina el siguiente estado.

NgRx no es necesario para todo proyecto Angular. Es más útil cuando varios componentes comparten estado o cuando quieres que las transiciones sean fáciles de rastrear y probar. Para estado local y simple, las señales o servicios de Angular pueden ser suficientes.

Cómo integrar Redux en Angular con NgRx

Los ejemplos siguientes usan la configuración con NgModule. Si tu aplicación usa componentes standalone, la configuración del store se realiza con las API standalone de NgRx.

1. Instalar NgRx Store en el proyecto

Instala el paquete compatible con la versión de Angular de tu proyecto:

npm install @ngrx/store

2. Definir el estado inicial del contador

El estado describe los datos que la aplicación guardará en el store:

// counter.state.ts
export interface CounterState {
    count: number;
}

export const initialCounterState: CounterState = {
    count: 0,
};

3. Crear acciones para cambiar el contador

Las acciones nombran los eventos que pueden cambiar el estado:

// counter.actions.ts
import { createAction } from '@ngrx/store';

export const increment = createAction('[Counter] Increment');
export const decrement = createAction('[Counter] Decrement');

4. Crear un reducer puro para el contador

El reducer es una función pura: recibe el estado actual y una acción, y devuelve el nuevo estado sin mutar el anterior:

// counter.reducer.ts
import { createReducer, on } from '@ngrx/store';
import { increment, decrement } from './counter.actions';
import { initialCounterState, CounterState } from './counter.state';

export const counterReducer = createReducer(
    initialCounterState,
    on(increment, (state) => ({ count: state.count + 1 })),
    on(decrement, (state) => ({ count: state.count - 1 }))
);

5. Registrar el reducer en el store global

Registra el reducer en el módulo principal para que el estado esté disponible bajo la clave counter:

// app.module.ts
import { NgModule } from '@angular/core';
import { StoreModule } from '@ngrx/store';
import { counterReducer } from './counter.reducer';

@NgModule({
    imports: [
        StoreModule.forRoot({ counter: counterReducer }),
    ],
})
export class AppModule {}

6. Seleccionar estado y despachar acciones

Define un selector para leer el contador y úsalo en el componente. Los componentes seleccionan datos del store y despachan acciones; no cambian el estado directamente:

// counter.component.ts
import { Component } from '@angular/core';
import { createFeatureSelector, createSelector, Store } from '@ngrx/store';
import { increment, decrement } from './counter.actions';
import { Observable } from 'rxjs';
import { CounterState } from './counter.state';

const selectCounterState = createFeatureSelector<CounterState>('counter');
const selectCount = createSelector(
    selectCounterState,
    (state) => state.count
);

@Component({
    selector: 'app-counter',
    template: `
        <p>Contador: {{ count$ | async }}</p>
        <button (click)="increment()">Increment</button>
        <button (click)="decrement()">Decrement</button>
    `,
})
export class CounterComponent {
    count$: Observable<number>;

    constructor(private readonly store: Store) {
        this.count$ = this.store.select(selectCount);
    }

    increment() {
        this.store.dispatch(increment());
    }

    decrement() {
        this.store.dispatch(decrement());
    }
}

La clave counter del selector debe coincidir con la registrada en StoreModule.forRoot. En una aplicación real, también conviene definir pruebas para el reducer y los selectores.

Conclusión: cuándo conviene usar NgRx

NgRx aporta estructura y trazabilidad cuando el estado se comparte entre distintas partes de la aplicación o cuando los cambios son difíciles de seguir. Para un estado pequeño y local, puede añadir complejidad innecesaria. Empieza por el alcance real de tus datos y elige la solución más simple que puedas probar y mantener.
